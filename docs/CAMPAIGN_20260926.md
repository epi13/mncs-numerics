## What Numeric is (confirmed, not changed)

Foundational representation-level contracts: checked/wrapping/
saturating integer intents, the f64 trap rule, conversions with an
explicit 2^53 exactness boundary, bounds/signedness, outcome enums
for foreseeable domain edges, generic reductions/masked reductions/
construction, flat 2x2/3x3 and nested MxN matrix representation.
Higher mathematics (transcendentals beyond shared-libm sin/cos,
solvers with pivoting, decompositions, FFTs, special functions,
statistics/optimization/autodiff tiers) belongs in `mncs-math`.
Full boundary: `docs/NUMERIC_MATH_BOUNDARY.md`, backed by Atlas
`numeric-primitives` (exclusive, numerics canonical) and
`numeric-algorithms` (shared, math builds over primitives).

## Newly pinned semantics (first machine-checked statement)

These were documented claims with no corpus coverage; the native
suites now pin them: shift counts modulo width (`1 << 64 == 1`),
signed `>>` arithmetic (`-8 >> 2 == -2`), division truncating
toward zero on negative sums (`mean_checked([-7,0,0,0]) == -1`),
remainder dividend sign (`-7 % 2 == -1`), `2^53 + 1 as f64 ==
2^53`, int→float→int round-trip and order preservation over
generated lanes, min/max duality and clamp idempotence over
generated lanes.

## Pressures (new or sharpened)

- P-019 (language, ergonomics, non-blocking): Nat inference from
  sequence literals. Repro + acceptance criteria in the ledger.
- Doctor stale profile registry (doctor, non-blocking): DOC102
  "unknown profile 0.18" on files the current toolchain accepts
  and runs. Record here; fixing belongs in `mncs-doctor`.
- Debug stale native-core binding (debug, non-blocking):
  `diagnose` fails with `stale_interface ... regenerate the host
  binding`; fail-closed (`sufficient: false`), no hallucinated
  diagnosis. Fixing belongs in `mncs-debug`.
- mncs-test assertion vocabulary (test, non-blocking): i64/bool/
  bytes only — no f64 or enum assertions, so exact-bit float checks
  and trap expectations cannot move in-language. The corpus/native
  division of labor documents this; a float/enum assertion tier
  would shrink the corpus surface. Not filed upstream; noted for
  the next Test run.
- Numeric/Math primitive overlap (coordination, non-blocking):
  `mncs-math` carries its own `scalar`/`float`/`vector`/`matrix`
  tiers intersecting Numeric ground. No migration while Math is
  mid-campaign; joint dedupe later.
- MNE131 on ambiguous cross-module names (language, by design):
  same-name functions from two `use`d modules do not overload;
  the native suites split int/float files accordingly. Recorded
  as a design fact, not a defect.
